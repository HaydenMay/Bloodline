# Credits & Asset Provenance

Every asset in this project must appear in this file with a verifiable source and
licence **before it is committed**. If an asset's provenance cannot be established,
it does not go in the repository.

See [DESIGN.md](DESIGN.md) §15 for the full asset and legal policy.

---

## The rules

1. **No assets we don't own.** Everything is either authored for this project or
   verifiably CC0 / public domain, recorded below.
2. **No trademarked names** — not other studios', not real racetracks, not real
   racehorses. Fictional tracks, procedurally generated horse names.
3. **"I found it online" is not a licence.** Neither is "it was free to download."
   A pack with no licence file grants no rights.
4. **Mechanics are fair game.** Game rules and systems are not copyrightable;
   only expression is.
